C++ 引用（reference）可以理解为“给已有对象起的一个别名”。对引用的操作，就是对其绑定对象的操作。

## 1. 基本语法

```cpp
int a = 10;
int& r = a;   // r 是 a 的引用

r = 20;       // 等价于 a = 20
std::cout << a; // 20
```

特点：

- 引用必须在定义时初始化。
- 引用一旦绑定某个对象，就不能再重新绑定到另一个对象。
- 对引用赋值，不是改变引用本身，而是改变被引用对象的值。
- 引用在语言层面不是对象，通常由编译器用指针实现，但不保证占用独立存储。
- 没有“空引用”。合法引用应当始终绑定到有效对象。

```cpp
int a = 1, b = 2;
int& r = a;
r = b;   // 不是让 r 改为引用 b，而是把 b 的值赋给 a
// 此时 a == 2，r 仍然引用 a
```

## 2. 常量引用

`const T&` 常用来避免拷贝，并且可以绑定临时对象。

```cpp
void print(const std::string& s) {
    std::cout << s << '\n';
}

const int& r = 42; // 合法，临时对象生命周期被延长到 r 的生命周期
```

常量引用可以绑定左值，也可以绑定右值：

```cpp
int x = 10;
const int& r1 = x;   // OK
const int& r2 = 20;  // OK
```

## 3. 引用作为函数参数

引用参数可以直接修改实参，也常用于避免大对象拷贝。

```cpp
void swap(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 1, y = 2;
    swap(x, y); // x=2, y=1
}
```

如果不需要修改，通常用 `const T&`：

```cpp
void print(const std::vector<int>& v);
```

## 4. 引用作为返回值

引用可以作为返回值，用于链式调用或返回容器元素等。

```cpp
int& at(std::vector<int>& v, int i) {
    return v[i];
}

int main() {
    std::vector<int> v{1, 2, 3};
    at(v, 1) = 100; // v[1] 变成 100
}
```

但要非常小心生命周期：

```cpp
int& bad() {
    int x = 10;
    return x; // 错误：返回局部变量引用，x 已销毁，悬垂引用
}
```

## 5. 引用与指针的区别

| 特性 | 引用 | 指针 |
|---|---|---|
| 必须初始化 | 是 | 否 |
| 可以为空 | 否 | 是 |
| 可以重新绑定 | 否 | 是 |
| `sizeof` | 被引用对象的大小 | 指针本身的大小 |
| 算术运算 | 不支持 | 支持 |
| 多级 | 不能直接声明引用的引用 | 可以有多级指针 |

例如：

```cpp
int a = 10;
int& r = a;
int* p = &a;

r = 20;   // 修改 a
*p = 30;  // 修改 a
```

## 6. 左值引用与右值引用

C++11 引入了右值引用 `T&&`。

- `T&`：左值引用，通常绑定左值。
- `const T&`：常量左值引用，可以绑定左值和右值。
- `T&&`：右值引用，通常绑定右值，用于移动语义和完美转发。

```cpp
int a = 10;
int& lr = a;        // 左值引用
int&& rr = 20;      // 右值引用，绑定临时值

std::string s = "hello";
std::string&& sr = std::move(s); // 右值引用
```

注意：具名的右值引用本身是左值。

```cpp
void f(int&& x) {
    // x 在这里是左值，因为它有名字
}
```

## 7. 引用折叠与完美转发

引用折叠规则：

```cpp
T& &   -> T&
T& &&  -> T&
T&& &  -> T&
T&& && -> T&&
```

在模板中，`T&&` 可能是“万能引用 / 转发引用”：

```cpp
template <typename T>
void wrapper(T&& arg) {
    target(std::forward<T>(arg)); // 保持左值/右值属性转发
}
```

如果传入左值，`T` 推导为 `T&`，折叠后 `T&&` 变成 `T&`；如果传入右值，则保持右值引用。

## 8. 常见陷阱

1. 返回局部变量的引用：
   ```cpp
   int& bad() {
       int x = 0;
       return x; // 悬垂引用
   }
   ```

2. 引用已经销毁的对象：
   ```cpp
   const std::string& r = getString(); // 如果返回临时对象，可能悬垂
   ```

3. 容器扩容后，之前保存的元素引用可能失效：
   ```cpp
   std::vector<int> v{1,2,3};
   int& r = v[0];
   v.push_back(4); // 可能扩容，r 可能失效
   ```

4. 混淆“引用重新绑定”和“赋值”：
   ```cpp
   int a = 1, b = 2;
   int& r = a;
   r = b; // 不是重新绑定，而是把 b 赋给 a
   ```

## 总结

| 语法形式        | 名称           | 可绑定对象                   | 能否通过它修改对象 | 典型用途             | 示例                                  |
| ----------- | ------------ | ----------------------- | --------- | ---------------- | ----------------------------------- |
| `T&`        | 非 const 左值引用 | 非 const 左值              | 能         | 修改实参、返回容器元素      | `int a = 1; int& r = a;`            |
| `const T&`  | 常量左值引用       | const/非 const 左值、右值/临时量 | 不能        | 函数参数避免拷贝、延长临时量寿命 | `const std::string& s = get();`     |
| `T&&`       | 非 const 右值引用 | 非 const 右值              | 能         | 移动语义、移动构造/赋值     | `std::string&& s = std::move(str);` |
| `const T&&` | 常量右值引用       | 右值                      | 不能        | 极少用，可用于重载区分      | `const int&& r = 42;`               |
| `T&&`（模板推导） | 转发引用 / 万能引用  | 左值、右值                   | 取决于推导     | 完美转发             | `template<class T> void f(T&& x);`  |
| `auto&&`    | auto 转发引用    | 左值、右值                   | 取决于推导     | 泛型代码、范围 for      | `auto&& x = expr;`                  |

> 注意：`T&&` 只有在模板参数推导或 `auto&&` 场景下才是转发引用；否则就是普通右值引用。

## 2. 特殊引用语法

| 语法形式 | 名称 | 说明 | 示例 |
|---|---|---|---|
| `T*&` | 指针的引用 | 可以修改指针本身 | `int* p; int*& r = p;` |
| `T (&)[N]` | 数组引用 | 保留数组大小，不能绑定指针 | `int a[3]; int (&r)[3] = a;` |
| `T (&)(Args...)` | 函数引用 | 绑定函数 | `void f(int); void (&r)(int) = f;` |

## 3. 引用折叠规则

| 写法 | 折叠结果 |
|---|---|
| `T& &` | `T&` |
| `T& &&` | `T&` |
| `T&& &` | `T&` |
| `T&& &&` | `T&&` |

## 4. 共同规则

- 引用必须初始化。
- 引用一旦绑定，不能重新绑定到另一个对象。
- 对引用赋值，是修改被引用对象，不是重新绑定。
- 没有“空引用”，合法引用应始终绑定有效对象。
- 返回引用时要特别注意对象生命周期，避免悬垂引用。
