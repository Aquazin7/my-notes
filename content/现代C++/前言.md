什么是现代C++？
**现代 C++** 并不是一个官方标准名称，而是社区对 **C++11 及之后一系列标准与编程风格**的统称。它通常以 **C++11 为分水岭**，涵盖 C++14、C++17、C++20、C++23，以及正在制定/发布的 C++26。核心目标是：在保持高性能和零开销抽象的同时，让 C++ 更安全、更简洁、更易维护。

### 现代 C++ 的核心特征

1. **RAII 与所有权明确**
   - 资源获取即初始化，用对象生命周期管理内存、文件、锁等。
   - 优先使用 `std::unique_ptr`、`std::shared_ptr`、`std::weak_ptr`，避免裸 `new/delete`。

2. **移动语义与右值引用**
   - `std::move`、`std::forward`、移动构造/赋值，减少不必要的拷贝。
   - 支持值语义和高效返回大对象。

3. **类型推导与简洁语法**
   - `auto`、`decltype`、范围 `for`、统一初始化 `{}`、结构化绑定。
   - Lambda 表达式让算法调用更自然。

4. **标准库大幅增强**
   - `optional`、`variant`、`any`、`string_view`、`span`、`filesystem`、`chrono`、`format` 等。
   - C++20 引入 `ranges`、`concepts`、协程、模块；C++23 继续完善。

5. **编译期计算**
   - `constexpr`、`consteval`、`constinit`、`if constexpr`。
   - 把更多工作放到编译期，提高运行时性能与类型安全。

6. **并发与内存模型**
   - `std::thread`、`mutex`、`atomic`、`future`、`async`。
   - C++11 起有了正式的多线程内存模型。

7. **模板与泛型编程改进**
   - 变参模板、别名模板、`concepts` 让模板约束更清晰，错误信息更可读。

### 风格对比

旧式 C++：
```cpp
std::vector<int>* v = new std::vector<int>;
for (std::vector<int>::iterator it = v->begin(); it != v->end(); ++it) {
    std::cout << *it << std::endl;
}
delete v;
```

现代 C++：
```cpp
auto v = std::vector{1, 2, 3};
for (int x : v) {
    std::cout << x << '\n';
}
```

现代 C++ 不是“把所有新特性都用上”，而是一种工程态度：  
**优先标准库和算法，明确所有权，减少手动资源管理，利用编译期检查，避免未定义行为，保持零开销抽象。**

总结：**现代 C++ = C++11 以来的新标准 + 以 RAII、值语义、智能指针、移动语义、STL、并发和编译期计算为核心的现代编程方式。**
